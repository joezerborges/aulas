QUEM SOMOS

Uma livraria feita para aprender junto

A Página de Papel é uma livraria fictícia criada como projeto educacional. Sua vitrine apresenta livros sobre programação, tecnologia e criatividade em uma interface simples e acolhedora.

Este site também é uma sala de aula: foi desenvolvido para demonstrar como Django organiza dados e páginas, enquanto Bootstrap ajuda a criar uma experiência responsiva.

Nossa ideia é que cada leitura desperte curiosidade e ajude alguém a dar o próximo passo no aprendizado.
